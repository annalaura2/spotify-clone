

# Clone do Spotify v2

Um web app clone do spotify feito em React.js e Next.js. <a href="https://github.com/annalaura2/spotify-clone" target="_blank">API</a> feita em .NET 7 e adequada para as necessidades do projeto.

A API está publicada na Azure com uma subscrição free, portanto a primeira requisição pode demorar.

Projeto iniciado 20/07/2026.
## Aprendizados

Este projeto foi desenvolvido como uma experiência prática de aprendizado em React, com o objetivo de recriar a interface do Spotify. A aplicação utiliza Next.js, React e JavaScript, explorando a construção de componentes, organização da interface e desenvolvimento de uma experiência de navegação inspirada na plataforma.
## Habilidades
TypeScript, React.js, Next.js, SCSS e MUITA paciência.
